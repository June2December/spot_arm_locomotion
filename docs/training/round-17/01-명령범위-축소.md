# 17차 — 명령 범위 축소

16차는 Lab Spot 전체 속도 범위 + dot off + std 0.5 를 한 번에 넣었다.
과속은 잡혔지만 `error_vel_xy` ~1.47, PLAY vx 비율 0.52, `terrain_levels` 0.38.
명령만 **중간 범위**로 줄인다. 보상·std·gait·clip은 16차 유지.

## 노브

| | 16차 | 17차 |
|---|---|---|
| resume | 15차 10146 | **16차 `2026-08-31_18-39-33/model_13144.pt`** |
| `lin_vel_x` | (-2.0, 3.0) | **(0.0, 2.0)** |
| `lin_vel_y` | (-1.5, 1.5) | **(-0.5, 0.5)** |
| `ang_vel_z` | (-2.0, 2.0) | **(-1.0, 1.0)** |
| `track_lin_vel_xy_dot` | 0 | 0 |
| tracking std | 0.5 | 0.5 |
| 무릎·clip·gait | — | 그대로 |

From scratch 아님. `mean_std` 0.22·에피소드 ~20초로 체크포인트는 살아 있음.
명령 분포만 좁혀서 추종·terrain 회복을 본다.

## 학습

```bash
cd /home/june/isaac_projects/spot_arm_locomotion
source scripts/isaaclab_env.sh
python scripts/train.py \
  --task Isaac-Velocity-Rough-Spot-Arm-v0 \
  --num_envs 4096 \
  --max_iterations 4500 \
  --resume \
  --load_run 2026-08-31_18-39-33 \
  --checkpoint model_13144.pt \
  --headless
```

런: `logs/rsl_rl/rough_spot_with_arm/2026-09-01_10-59-54/` · 목표 iter 13144 → **17644**.

| TensorBoard | 보이면 | 뜻 |
|---|---|---|
| `error_vel_xy` | **1.0 이하로 하락** | 추종 회복 |
| `terrain_levels` | **3+** | 커리큘럼 회복 |
| `mean_std` | **>2** | 즉시 끊음 |
| `mean_episode_length` | **18 s+** | 걸음 유지 |

