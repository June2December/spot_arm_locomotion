# 16차 — 속도 명령·추종 정리

## 학습

```bash
cd /home/june/isaac_projects/spot_arm_locomotion
source scripts/isaaclab_env.sh
python scripts/train.py \
  --task Isaac-Velocity-Rough-Spot-Arm-v0 \
  --num_envs 4096 \
  --max_iterations 1500 \
  --resume \
```
